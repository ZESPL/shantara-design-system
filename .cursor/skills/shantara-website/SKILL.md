# Shantara Website

Canonical skill lives with the Website Kit so humans and agents read the same files:

**`ui_kits/website/SKILL.md`**

Read that file first. Its sibling references (`skill-ia.md`, `skill-sections.md`, `skill-content.md`, `skill-copy.md`, `skill-technical.md`, `skill-qa.md`) hold the inventories and checklists.

Public website language is governed by `skill-copy.md`. Read it before writing or rewriting visitor-facing copy.

The Website Kit in the design-system catalog is the browsing surface. Sample screens in `ui_kits/website/` illustrate the skill — they are not a production website.

Multilingual architecture is first-class: planned languages `en ar de fr ru hi ml`, English published first, Arabic the first future localisation. Central config is `locales.js`. Read **§15 Multilingual Architecture** in the canonical skill before adding a route, string, or content type.

Also read the design-system skill at the repo root (`SKILL.md`) before inventing visual or clinical language.

Internal marketing audience (ICP) lives in `docs/icp.md`. Do not duplicate it. Do not use internal ICP names as public headings or keywords without search evidence.

Rates appear only on dedicated tariff surfaces. Do not invent or scatter prices. Locale is not currency.

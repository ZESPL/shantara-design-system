A large Light quote, left-aligned, with small labelled facts beneath.

```jsx
<QuoteBlock quote="…" cite="Guest, United Arab Emirates" facts={[{ label: "What brought them here", text: "…" }]} />
```

**Content rule.** Only consented, recorded words. `content/testimonials/` is empty, so the kit uses this block for brand statements only — never a composed testimonial. **Responsive:** facts stack on phones, two columns from 760px.

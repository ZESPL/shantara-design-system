The contract

Built in, not bolted on

Deliberately below 3:1 — never load-bearing

  • --border-subtle (1.2) and --border-default (1.6–1.8): decorative hairlines only — dividers, card edges, table rules. Controls use --border-control, which clears 3:1 on every light ground.
  • --surface-accent against the page (1.4): the Gold Crayola button carries a --color-gold-800 hairline so its boundary, not its fill, does the work.
  • --surface-brand-soft focus halo (1.2): a soft echo behind the 2 + 2px Himalaya focus ring, which is the actual indicator.
  • Gold Crayola and the six accents are never text colours on light grounds. They are large calm areas, and the audit records the prohibition rather than hiding it.

Component contract

  • Focus — every control shows --ring-focus (2px page-colour offset + 2px Himalaya, 7.4:1); --ring-focus-inverse on dark and over photography.
  • Names — IconButton requires label; Tag's remove is aria-label="Remove"; Logo ships real alt; decorative photography is alt="".
  • Keyboard — Tabs follows the ARIA tablist contract (arrows select, Home/End, roving tabindex). Accordion exposes aria-expanded. Dialog takes focus on open, traps Tab, closes on Escape and restores focus.
  • Targets — 2.5.8 minimum 24×24 everywhere: --control-sm is 32px, checkbox and radio rows are floored at 24px, the tag remove is a 24px target around a 16px glyph. Mobile surfaces use --tap-min 44px.
  • Status — Toast is role="status"; Spinner carries an accessible label. Colour never carries meaning alone: badges pair tone with a word.
  • Hover content — Tooltip is dismissible with Escape and linked by aria-describedby (1.4.13). Never put essential information there.
  • Motion — no parallax, no autoplay, nothing above 420ms except the 1200ms breathing Spinner; safe under 2.3.3.

Known gaps, honestly

  • 1.4.10 Reflow — the UI kits are desktop compositions with a responsive override layer down to 320px. A production build should carry real breakpoints rather than !important overrides.
  • 2.5.5 Target Size (AAA) — --control-sm at 32px meets AA's 24px but not AAA's 44px. Deliberate, for dense desktop toolbars; mobile never uses it.
  • 3.3.x — the enquiry flow validates on submit in the kit only. Real error identification, suggestion and prevention (3.3.1/3.3.3/3.3.4) belong to the implementation.
  • Screen-reader testing — this audit is programmatic. Nothing here substitutes for a pass with NVDA, JAWS and VoiceOver.

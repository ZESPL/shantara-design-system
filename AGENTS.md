# Agent index — Shantara Design System

Read this before inventing copy, programmes, rates, or IA.

1. **Skills.** Read root [`SKILL.md`](SKILL.md). For the public marketing website, also read [`ui_kits/website/SKILL.md`](ui_kits/website/SKILL.md) and [`ui_kits/website/skill-copy.md`](ui_kits/website/skill-copy.md). Production stack for **shantara.life** (Astro, Keystatic, Tailwind, Netlify, OpenPanel, …): [`ui_kits/website/skill-stack.md`](ui_kits/website/skill-stack.md). Folder layout, routes and build checks for that repo: [`ui_kits/website/skill-structure.md`](ui_kits/website/skill-structure.md). Image storage, compression and delivery: [`ui_kits/website/skill-images.md`](ui_kits/website/skill-images.md). Premium design and motion: [`ui_kits/website/skill-premium.md`](ui_kits/website/skill-premium.md). For any presentation or deck (PowerPoint, Google Slides, Keynote, Canva, HTML, PDF): [`.cursor/skills/shantara-premium-presentations/SKILL.md`](.cursor/skills/shantara-premium-presentations/SKILL.md). The HTML brand-deck template is [`templates/brand-deck/`](templates/brand-deck/).
2. **Facts.** Prefer [`content/`](content/) first. Use [`docs/handbook.txt`](docs/handbook.txt) for policies, conflicts, and `[TO CONFIRM]` — not for hero or marketing copy. Never quote handbook §15 (the “wellness retreat” 30-second line) on public pages. Never use “patients” or “wellness retreat” as public product language.
3. **Audience.** [`docs/icp.md`](docs/icp.md) is internal. Do not paste ICP names or competitor paragraphs onto pages. Do not store ICP IDs on content records; ICPs are for strategy, campaigns and CRM only.
4. **Samples.** Files under `ui_kits/website/screens/` illustrate composition. They are not the production site. Production URLs are `/en/…`, not `#/en/…`.
5. **Bundle.** Do not read [`_ds_bundle.js`](_ds_bundle.js) for copy, programmes, or rates. It is components-only.
6. **Leave alone** unless the task needs them: catalog chrome (`catalog.js`, `index.html`), `.agents/skills/` (generic motion/Swift/Sonner), `scraps/`, and `uploads/`.

Rates, currencies and validity dates are not stored in this design system or its documentation. Production rates live only in the shantara.life Keystatic tariff. Everywhere else, link to the tariff page and never quote a rate. [`content/tariff.json`](content/tariff.json) holds only the tariff structure (inclusions, supplements, payment terms, cancellation). Nothing the rate sheet marks internal ever enters this folder.

What to take vs leave when consuming this folder: [`docs/use.md`](docs/use.md).
